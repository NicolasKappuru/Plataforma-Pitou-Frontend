"""Contrato de API de los tres plugins gestionados.

Autenticacion: Authorization: Bearer <jwt_token>
Las rutas no llevan prefijos adicionales como /api/plugins/.

Reglas comunes:
- POST acepta entre 1 y 5 elementos.
- PUT acepta entre 1 y 5 elementos y cada elemento requiere id.
- DELETE recibe una lista de ids.
- id y posicion son generados por el backend. Nunca se envian al crear.
- posicion es global dentro del concepto y combina imagenes, bloques y formulas.
- concepto es obligatorio al crear y puede ir en cada elemento o en la raiz.
- GET por concepto usa ?concepto=<id>.
"""

# Imagenes

"""
GET /gestor_imagenes/imagen/?concepto=1
GET /gestor_imagenes/imagen/1/

La primera ruta lista las imagenes del concepto y la segunda devuelve una imagen
por id. La respuesta de lista devuelve solo las URLs:
{
  "imagenes": ["https://..."]
}
"""

"""
POST /gestor_imagenes/imagen/
Content-Type: multipart/form-data

Campos:
- concepto: id del concepto, obligatorio.
- imagenes: archivo, obligatorio; repetir de 1 a 5 veces.
- nombre_plugin: opcional; repetir en el mismo orden de los archivos.
- descripcion_plugin: opcional; repetir en el mismo orden de los archivos.

No enviar id ni posicion. El backend genera ambos valores.

curl -X POST "http://localhost:8000/gestor_imagenes/imagen/" \
  -H "Authorization: Bearer <jwt_token>" \
  -F "concepto=1" \
  -F "imagenes=@imagen1.png" \
  -F "imagenes=@imagen2.jpg" \
  -F "nombre_plugin=Diagrama 1" \
  -F "nombre_plugin=Diagrama 2" \
  -F "descripcion_plugin=Descripcion 1" \
  -F "descripcion_plugin=Descripcion 2"
"""

"""
PUT /gestor_imagenes/imagen/
Content-Type: application/json

{
  "imagenes": [
    {
      "id": 10,
      "nombre_plugin": "Diagrama actualizado",
      "descripcion_plugin": "Nueva descripcion"
    }
  ]
}

Para reemplazar un archivo se usa multipart/form-data. La posicion existente
se conserva y no se recibe desde el frontend.
"""

"""
DELETE /gestor_imagenes/imagen/
Content-Type: application/json

{"ids": [10, 11]}

Tambien acepta form-data repetido: ids=10&ids=11.
"""
